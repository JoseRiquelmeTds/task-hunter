# Rubrica de ranking

> **Status: pendente.** Critérios tirados da especificação. Faltam os pesos e o desempate.

Cada critério dá uma nota de 0 a 5. A nota final é a soma ponderada.

| Critério | Como medir | Peso |
| --- | --- | --- |
| Prioridade no Jira | Highest = 5 … Lowest = 1 | a definir |
| Sprint atual | está na sprint ativa = 5, fora = 0 | a definir |
| Desbloqueia outras tasks | número de links "blocks" abertos | a definir |
| Clareza da descrição | critérios de aceite explícitos, passos de reprodução, escopo delimitado | a definir |
| Tamanho estimado | menor = nota maior | a definir |
| Idade do ticket | mais antiga = nota maior | a definir |

## Desempate

A definir.
